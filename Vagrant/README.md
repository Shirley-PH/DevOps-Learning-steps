# Configuration and Management of Vagrant

A quick reference guide and foundational concepts for setting up and managing development environments using Vagrant.

## Requirements
Make sure you have the following tools installed on your system:
- **Vagrant**: [Download Link](https://developer.hashicorp.com/vagrant/install)
- **VirtualBox**: [Download Link](https://www.virtualbox.org/wiki/Downloads)
- **Git**: [Download Link](https://git-scm.com/install)

---

## Basic Directory Structure
```bash
├── Vagrantfile        # Vagrant's main configuration file
├── .vagrant/          # Local files generated by Vagrant (state data)
├── config/            # Custom configuration directory
├── scripts/           # Provisioning and automation scripts
└── docs/              # Project documentation

```
## Essential Vagrant Commands
```bash
# Start and provision the virtual machine
vagrant up

# Check the current status of the VM
vagrant status

# Force destroy the virtual machine
vagrant destroy -f

# Reload configuration changes and re-provision
vagrant reload --provision

# Display the HostName/IP configuration for SSH
vagrant ssh-config | grep HostName

# Access the virtual machine via SSH
vagrant ssh
```
## Basic Configuration of `VagrantFile` file

**Basic Template**

Here is an example of a standard `VagrantFile` setup:

```bash
Vagrant.configure("2") do |config|
	#Type of Operation System (Box)
	config.vm.box = "ubuntu/jammy64" 
	
	# Network configuration (IP provided by your local router/DHCP)
	config.vm.network "public_network", ip: "192.168.1.50" 

	# Provider settings (e.g., VMware or VirtualBox)
	config.vm.provider "vmware_desktop" do |vmware|
		vmware.vmx["memsize"] = "1024" # Memory size in MB
		vmware.vmx["numvcpus"] = "2" # Number of CPUs
	end
end
```

## Syncing Local Folders

When syncing local directories to your virtual machine, ensure the destination path aligns with the guest operating system's directory structure.

For example, to map a local scripts folder to /opt/scripts inside an Ubuntu guest:

```bash
Vagrant.configure("2") do |config|
    config.vm.box = "ubuntu/jammy64"
    
    # Sync local 'scripts' directory to the guest VM path
    config.vm.synced_folder "./scripts", "/opt/scripts"
end
```
> Note: After saving modifications to your `Vagrantfile`, apply the changes by running `vagrant reload` in your terminal.
